# AtomLab

Интерактивная образовательная платформа виртуальных экспериментов для школьников Узбекистана (MVP). Язык по умолчанию — русский; узбекская локализация частичная, а динамический текст экспериментов может оставаться на русском.

**Стек:** React 19 + Vite + Tailwind CSS v4 + Zustand + React Router · Vitest + Playwright · только JavaScript/JSX (без TypeScript).

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # production-сборка в dist/
npm test           # unit-тесты (Vitest) научных моделей, реестра и хранилища
npm run test:e2e   # браузерные тесты Playwright (поднимает dev-сервер сам)
npm run lint
```

Для e2e один раз: `npx playwright install chromium`.

## Что внутри

- 16 экспериментов (2 на предмет × 8 предметов): физика, химия, биология, география, математика, астрономия, информатика, история.
- Режимы **Академия** (класс → предмет → тема → эксперимент, ход работы, задания, тест) и **Исследование** (шире диапазоны, необязательные миссии, «песочница» с неподдерживаемыми инструментами и пояснениями).
- Под каждым экспериментом: изучаемая тема, что объясняет, чему научишься, как работает, задания, проверка, вывод, связь со школьной программой.
- Прогресс хранится локально (`localStorage`, версионированная схема, устойчива к повреждённым данным).

## Честно о статусе

- Соответствие школьной программе Узбекистана **не сверено** с официальными источниками (все привязки — provisional). См. `docs/CURRICULUM_SOURCES.md`.
- 3D не используется: «Мастерская оборудования» (`/workshop`) — 2D-демонстрация. См. `docs/PHASE9_INTEGRATION_REPORT.md` и `docs/PHASE9_EXPERIMENT_AUDIT.md`.
